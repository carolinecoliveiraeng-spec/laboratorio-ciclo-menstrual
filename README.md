# Laboratório do Ciclo Menstrual

Laboratório digital interativo de Biologia para o Ensino Médio.

## Arquivos
- `index.html`: página principal, estações de investigação e referências científicas.
- `style.css`: identidade visual e layout responsivo.
- `app.js`: navegação, interações, simulador e questionário.

## Publicação
O projeto pode ser hospedado pelo GitHub Pages usando a branch `main` e a pasta `/ (root)`.

O laboratório funciona no navegador e não exige backend nem cadastro dos estudantes.
