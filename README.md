# Laboratório do Ciclo Menstrual

Recurso digital interativo de Biologia para o Ensino Médio.

## Estrutura
- `index.html`: página principal.
- `css/style.css`: estilos e layout responsivo.
- `js/app.js`: navegação, interações, simulador e quiz.
- `assets/imagens/`: espaço para imagens e recursos visuais adicionais.

## Publicação no GitHub Pages
1. Envie todos os arquivos e pastas deste projeto para a raiz do repositório.
2. No GitHub, acesse Settings > Pages.
3. Em Build and deployment, escolha Deploy from a branch.
4. Selecione `main` e `/ (root)` e salve.
5. Aguarde a publicação e abra o endereço informado pelo GitHub Pages.

Este projeto não exige backend nem coleta dados dos estudantes.
